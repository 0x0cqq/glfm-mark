# GLFM 语法支持与限制

本文件描述当前实现支持的语法、编辑方式、导出规则与已知限制。
导入与导出行为由源码保留层保证：未修改的块逐字符复用原文。

## 交互形式

- **直接编辑**：在正文中编辑文本和结构。
- **专用编辑**：正文显示结果，通过节点内按钮或弹窗修改源码。
- **源码保留**：显示源码卡片，允许修改原文，不做不可靠的结构转换。

## 外观主题

- `material`（默认）：正文继承 MkDocs Material 的字号、间距、表格、提示与折叠样式，控件沿用宿主配色。
- `modern`：独立的宽松写作排版、圆角、选区面板与工具菜单。
- 两套主题均支持下列交互，亮暗配色跟随宿主 `default` / `slate`。
- 完整 Material 外观需要宿主加载 Material CSS；独立演示页提供基础排版与两套主题切换。
- 代码语言栏、行号与格式工具属于编辑辅助控件；正文排版对齐不要求编辑辅助控件出现在阅读页。

## 写作交互

选中文字后出现格式工具栏，可切换粗体、斜体、删除线、行内代码、链接和清除格式。
选区工具栏可通过 Alt+F10 聚焦，左右方向键移动，Escape 关闭并返回正文。

编辑区左侧显示每个顶层块在当前导出 Markdown 中的起始行及 H1–H6、P、列表等类型。
这是源码行号：表格和列表显示该顶层块的起始行，视觉自动折行不增加源码行号。
源码模式显示所有物理行，横向滚动保持行号对齐。

大纲按标题导航；专注模式淡化当前块以外的内容。选区、行号、大纲与专注状态不改变 Markdown。
工具栏将常用格式常驻，表格、图片、代码、公式、图表和提示块收纳在插入菜单。

### 格式快捷键

Windows/Linux 使用 Ctrl，macOS 使用 Cmd。以下格式快捷键作用于编辑模式：

| 操作 | 快捷键 |
|---|---|
| 粗体、斜体、行内代码 | Mod+B、Mod+I、Mod+E |
| 删除线、清除行内格式 | Mod+Shift+S、Mod+Shift+M |
| 链接 | Mod+K |
| 正文、标题 1–6 | Mod+Alt+0、Mod+Alt+1–6 |
| 有序、无序、任务列表 | Mod+Shift+7、8、9 |
| 引用 | Mod+Shift+B |
| 列表缩进、取消缩进 | Tab、Shift+Tab |
| 硬换行 | Shift+Enter |
| 撤销、重做 | Mod+Z、Mod+Shift+Z |
| 保存（配置宿主保存接口后） | Mod+S |
| 专注模式 | Mod+Shift+F |

快捷键面板可从右上角键盘按钮打开。只读状态关闭修改操作。

## 功能矩阵

| 内容 | 交互 | 导出 |
|---|---|---|
| 段落、六级标题 | 直接编辑 | 修改块使用标准 GLFM |
| 粗体、斜体、删除线、行内代码 | 直接编辑 | `**`、`*`、`~~`、足够长的反引号 |
| 普通引用、多行引用 | 直接编辑 | `>` 引用；多行引用保留 `>>>` 围栏 |
| 无序、有序、任务列表 | 直接编辑、缩进、取消缩进 | `-`；保留有序列表起始序号；保留任务状态 |
| 分隔线、硬换行 | 直接编辑或插入 | `---`；反斜杠加换行 |
| 链接 | 弹窗编辑文字、地址、标题 | 保留原始相对地址；自动链接不重复包裹 |
| 图片 | 选中或双击图片后编辑地址、替代文本、标题；支持上传 | `![alt](src "title")`，保留 `{width=}` 尺寸属性 |
| 音频、视频、其他附件 | 原子行内节点 | 未修改时复用原文；新上传使用宿主返回的 Markdown |
| 管道表格 | 编辑单元格 | GLFM 管道表格，保留列对齐 |
| GLFM 提示块 | 直接编辑正文，工具栏切换类型 | `> [!TYPE]`，默认标题不写入源码 |
| `<details>` / `<summary>` | 节点视图编辑标题与正文 | `<details>` 与 `<summary>`；`open` 状态来自源码 |
| 普通代码块 | 节点视图编辑语言与代码 | 围栏代码块，围栏长度按内容调整 |
| 数学公式 | 节点视图显示 KaTeX，弹窗编辑 | 保留原定界方式；新建使用 `$`…`$` 与 ```` ```math ```` |
| Mermaid | 节点视图显示图表，弹窗编辑 | `mermaid` 围栏 |
| GitLab 用户、Issue、MR 等引用 | 原子行内节点 | 输出原始引用表达式 |
| Emoji 短代码 | 本地 Unicode Emoji 字典 | `:name:` |
| 脚注引用 | 只读展示 | `[^label]` |
| 脚注定义 | 源码保留块 | 原样输出 |
| 引用式链接及其定义 | 源码保留块 | 原样输出，不自动改为行内链接 |
| GLFM 目录标记 `[[_TOC_]]` / `[TOC]` | 源码保留块 | 原样输出 |
| front matter、HTML 注释 | 源码保留块 | 原样输出 |
| 任意 HTML、复杂 HTML 表格、未知扩展 | 源码保留块 | 原样输出 |
| MkDocs `!!!` 提示块 | 直接编辑标题和正文，支持 `theorem`、`note` 等类型 | 保留 MkDocs 类型、修饰词及四空格正文缩进 |
| MkDocs `???` 提示与 `===` 标签页 | 完整容器作为源码保留块修改 | 原样保留宿主方言 |
| 其他 MkDocs 专属语法（宏等） | 源码保留块或普通源码展示 | 不自动转换方言 |
| PlantUML、Kroki 和其他图表围栏 | 围栏代码块编辑 | 保留围栏及内容，不自动调用外部图表服务 |

## 源码保留粒度

- 保留单位是顶层源码块。
- 修改表格单元格会重写整个表格；修改列表项会重写整个顶层列表。
- 修改已有块时保留相邻间隔与首尾空白；新增或重排块使用文档的默认换行。
- 不承诺修改块内部的逐字符最小差异。
- 其他未修改块复用原始字符串，包括重复段落和重复表格。

## 规范化输出

规范化只作用于用户修改或新建的块：

- 标题：ATX 形式（`#` 至 `######`）。
- 粗体 `**`，斜体 `*`，删除线 `~~`。
- 无序列表使用 `-`；有序列表保留起始序号并使用 `.`。
- 任务列表使用 `- [ ]`、`- [x]`、`- [~]`。
- 分隔线 `---`；普通硬换行使用反斜杠加换行。
- 表格单元格只允许行内内容；不提供合并单元格。
- 行内代码与代码围栏使用足够长的反引号。
- 新建块级公式使用 `math` 围栏；新建行内公式使用 `$`…`$`。
- 新建折叠块保存为默认关闭；编辑时临时展开，点击折叠箭头切换展示，summary 文字可直接编辑。

公式与代码的原始定界符、信息字符串属于源码数据；修改内容时只在原定界符不足
以安全包裹新内容时调整其长度。

## 未修改内容的保证

- 未编辑文档逐字符原样导出。
- 修改一个源码块不会重新格式化其他未修改块。
- 首尾空白、BOM、混合换行与重复内容都按原文保留。
- 保存、导出、预览与主题变化都不会重建源码基线；只有外部载入新文档，或修改
  源码后成功重新进入富文本模式，才建立新基线。

## 已知限制

- 脚注、引用式链接和未知 HTML 在首版不开放结构化富文本修改，只能通过源码编辑。
- GitLab 引用显示原始表达式（如 `@alice`、`#12`、`!34`），不查询项目数据。跨项目等未识别表达式作为普通文本保留。
- 混合普通/任务列表及有序任务列表保留列表类型，勾选标记通过源码修改。
- Emoji 使用 markdown-it-emoji 字典，不识别的短代码保留文字。
- 代码高亮使用 lowlight，与 GitLab 的 Pygments 配色不保证逐 token 一致。
- Mermaid 使用 SVG 文本标签，保留严格净化策略。
- 渲染结果缺少 `data-sourcepos` 时，整篇作为单个源码块载入，界面显示降级状态。
- 导入、源码重解析与预览在浏览器内完成；公式、图表、高亮及 Emoji 资源随静态站点部署。
- 原始 HTML 作为源码展示；闭合的 Markdown details 及表格内 `<br>` 支持结构化编辑。
- MkDocs 目录式页面中的相对 `.md` 链接在编辑区与预览中仍指向 `.md` 地址；
  当前只解析相对路径，不执行 MkDocs 的页面路由转换，导出的源码地址保持不变。
- 脚注定义、引用式链接及目录标记当前以源码展示；不生成脚注列表或目录导航。
- 未实现斜杠菜单、拖拽排序、协同编辑与自动保存。

## 展示基线

- MkDocs `1.6.1`
- MkDocs Material `9.7.7`
- `pymdown-extensions` `11.0.2`
- 亮色 `default` 与暗色 `slate`
- KaTeX、Mermaid、lowlight 版本见 `package.json`

宿主存在 Material 样式时继承 `.md-typeset` 与 `--md-*` 变量；全部编辑控件使用
`glfm-editor__*` 前缀，不覆盖宿主的全局标题、表格或按钮样式。
