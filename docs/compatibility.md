# GLFM 语法支持与限制

本文件描述当前实现支持的语法、编辑方式、导出规则与已知限制。
导入与导出行为由源码保留层保证：未修改的块逐字符复用原文。

## 交互形式

- **直接编辑**：在正文中编辑文本和结构。
- **专用编辑**：正文显示结果，通过节点内按钮或弹窗修改源码。
- **源码保留**：显示源码卡片，允许修改原文，不做不可靠的结构转换。

## 功能矩阵

| 内容 | 交互 | 导出 |
|---|---|---|
| 段落、六级标题 | 直接编辑 | 修改块使用标准 GLFM |
| 粗体、斜体、删除线、行内代码 | 直接编辑 | `**`、`*`、`~~`、足够长的反引号 |
| 普通引用、多行引用 | 直接编辑 | `>` 引用；多行引用保留 `>>>` 围栏 |
| 无序、有序、任务列表 | 直接编辑、缩进、取消缩进 | `-`；保留有序列表起始序号；保留任务状态 |
| 分隔线、硬换行 | 直接编辑或插入 | `---`；反斜杠加换行 |
| 链接 | 弹窗编辑文字、地址、标题 | 保留原始相对地址；自动链接不重复包裹 |
| 图片 | 弹窗编辑地址、替代文本、标题；支持上传 | `![alt](src "title")`，保留 `{width=}` 尺寸属性 |
| 音频、视频、其他附件 | 原子行内节点 | 未修改时复用原文；新上传使用宿主返回的 Markdown |
| 管道表格 | 编辑单元格 | GLFM 管道表格，保留列对齐 |
| GLFM 提示块 | 直接编辑正文，工具栏切换类型 | `> [!TYPE]`，默认标题不写入源码 |
| `<details>` / `<summary>` | 节点视图编辑标题与正文 | `<details>` 与 `<summary>`；`open` 状态来自源码 |
| 普通代码块 | 节点视图编辑语言与代码 | 围栏代码块，围栏长度按内容调整 |
| 数学公式 | 节点视图显示 KaTeX，弹窗编辑 | 保留原定界方式；新建使用 `$`…`$` 与 ```` ```math ```` |
| Mermaid | 节点视图显示图表，弹窗编辑 | `mermaid` 围栏 |
| GitLab 用户、Issue、MR 等引用 | 原子行内节点 | 输出原始引用表达式 |
| Emoji 短代码 | 显示 GitLab 返回的 Emoji | `:name:` |
| 脚注引用 | 只读展示 | `[^label]` |
| 脚注定义 | 源码保留块 | 原样输出 |
| 引用式链接及其定义 | 源码保留块 | 原样输出，不自动改为行内链接 |
| GLFM 目录标记 `[[_TOC_]]` / `[TOC]` | 源码保留块 | 原样输出 |
| front matter、HTML 注释 | 源码保留块 | 原样输出 |
| 任意 HTML、复杂 HTML 表格、未知扩展 | 源码保留块 | 原样输出 |
| MkDocs 专属语法（提示、标签页、宏等） | 源码保留块或普通源码展示 | 不自动转换方言 |
| PlantUML、Kroki 和其他图表围栏 | 围栏代码块编辑 | 保留围栏及内容，不自动调用外部图表服务 |

## 源码保留粒度

- 保留单位是顶层源码块。
- 修改表格单元格会重写整个表格；修改列表项会重写整个顶层列表。
- 不承诺修改块内部的逐字符最小差异。
- 其他未修改块复用原始字符串，包括重复段落和重复表格。

## 规范化输出

规范化只作用于用户修改或新建的块：

- 标题：ATX 形式（`#` 至 `######`）。
- 粗体 `**`，斜体 `*`，删除线 `~~`。
- 无序列表使用 `-`；有序列表保留起始序号并使用 `.`。
- 任务列表使用 `- [ ]`、`- [x]`、`- [~]`。
- 分隔线 `---`；普通硬换行使用反斜杠加换行。
- 表格单元格只允许行内内容；不提供合并单元格。
- 行内代码与代码围栏使用足够长的反引号。
- 新建块级公式使用 `math` 围栏；新建行内公式使用 `$`…`$`。
- 新建折叠块默认关闭。

公式与代码的原始定界符、信息字符串属于源码数据；修改内容时只在原定界符不足
以安全包裹新内容时调整其长度。

## 未修改内容的保证

- 未编辑文档逐字符原样导出。
- 修改一个源码块不会重新格式化其他未修改块。
- 首尾空白、BOM、混合换行与重复内容都按原文保留。
- 保存、导出、预览与主题变化都不会重建源码基线；只有外部载入新文档，或修改
  源码后成功重新进入富文本模式，才建立新基线。

## 已知限制

- 脚注、引用式链接和未知 HTML 在首版不开放结构化富文本修改，只能通过源码编辑。
- 展示地址、引用标题等 GitLab 返回值不进入业务源码；导出始终使用原始写法。
- 代码高亮使用 lowlight，与 GitLab 的 Pygments 配色不保证逐 token 一致。
- 当前 Mermaid 流程图存在节点文字缺失的问题（`flowchart TD` 下的 `A-->B` 可复现）；
  节点框、连线与原始源码仍保留。
- 渲染结果缺少 `data-sourcepos` 时，整篇作为单个源码块载入，界面显示降级状态。
- standalone 需要宿主渲染服务，当前包未提供完整本地 GLFM 引擎。
  开发演示使用近似渲染器，MkDocs 离线示例只查询内置文档的 HTML；编辑后的预览与
  源码重解析需要能处理新内容的渲染器。依赖与替代条件见 [README](../README.md#渲染依赖与离线能力)。
- 未实现浮动气泡菜单、斜杠菜单、拖拽排序、协同编辑与自动保存。

## 展示基线

- MkDocs `1.6.1`
- MkDocs Material `9.7.7`
- `pymdown-extensions` `11.0.2`
- 亮色 `default` 与暗色 `slate`
- KaTeX、Mermaid、lowlight 版本见 `package.json`

宿主存在 Material 样式时继承 `.md-typeset` 与 `--md-*` 变量；全部编辑控件使用
`glfm-editor__*` 前缀，不覆盖宿主的全局标题、表格或按钮样式。
