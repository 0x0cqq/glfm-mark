# 0008. 共用编辑能力的 Material 与现代主题

- 状态：accepted
- 日期：2026-09-14
- 关联：[当前架构](../architecture.md)、[写作交互](../compatibility.md#写作交互)

## 背景

用户要求现代编辑体验，同时明确保留与 MkDocs Material 严格对齐的默认外观。
选区格式框、行号和快捷键应在两个主题中都可使用。

## 决策

公开 `theme: 'material' | 'modern'`，默认 Material，编辑器、只读预览与静态挂载共用。
Material 正文继承宿主真实样式，现代主题的排版规则限定在自身作用域内。
工具栏、行号、大纲、对话框与快捷键共用，外观切换只改属性，不重建编辑器。
独立页面提供基础排版；严格 Material 对齐以加载宿主样式的实际站点为验收环境。

## 理由与取舍

复用宿主样式能够跟随站点字体、主题变量与阅读排版，避免维护一份容易偏离的 Material 副本。
现代主题具有独立视觉规则，但无需维护第二套编辑逻辑。行号和代码语言栏等编辑控件
属于额外界面，不改变保存的 Markdown 或阅读页结构。

## 后果与验证

在真实 MkDocs Material 页面比较标题、段落、表格、提示块、折叠块的计算样式，
覆盖亮暗与窄屏。两个主题均运行选区格式、快捷键、源码切换、行号、大纲与撤销的浏览器测试。
主题和展开状态须保持 Markdown 不变。
